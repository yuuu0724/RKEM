## 建议测试补充方案

| 测试项 | 建议方法 | 输出材料 |
| --- | --- | --- |
| HMI 启动 | 在安装目录运行 `timeout 3 ./main_process -platform offscreen`，再正常显示环境运行 `./main_process` | 启动日志、主界面截图 |
| 摄像头设备 | 确认 `/dev/video21`、`/dev/video23` 存在且未被占用，运行 HMI 观察两路预览 | 设备列表截图、预览截图 |
| 模型加载 | 启动 HMI 后观察 OCR/视觉模型状态，保存控制台日志 | 模型加载日志截图 |
| 单槽检测 | 输入已知芯片型号模板，放置正常样品和缺陷样品分别测试 | 检测结果截图、OCR/缺陷数据表 |
| 连续槽位 | 连接下位机或模拟串口回包，完成 4 个槽位循环 | 串口日志、槽位结果截图 |
| 员工管理 | 连接员工识别设备，完成录入、签到、签退、删除 | 操作截图、数据库记录截图 |
| 疲劳告警 | 测试闭眼、张嘴和正常状态，记录持续时间 | 疲劳截图、告警日志 |
| 云端上传 | 启动 HTTP 服务端接收请求或抓包 | 请求 JSON、响应日志 |
| 连续运行 | 运行 2 小时以上，记录日志大小、崩溃情况、温度和资源占用 | 稳定性测试表 |
